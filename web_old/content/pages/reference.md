# API reference

Browse compiled Hypostructure modules and declarations. Types, docstrings, dependencies, and source ranges come from the Lean environment used to build this documentation snapshot.

## How to use the reference

Begin with the guides and strategy catalog. Use this index when you need an exact type, namespace, source definition, or dependency boundary.

## Trust and provenance

Every published source excerpt is allowlisted, hashed, and bound to the snapshot manifest. A declaration page reports compiled environment facts; curated prose cannot invent or rename an API declaration.
