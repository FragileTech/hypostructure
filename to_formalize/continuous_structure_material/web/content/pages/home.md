# Build proofs from a Problem and a DAG

Hypostructure’s public API turns a mathematical theorem into two explicit values: a `Core.ProblemDefinition` containing the mathematics and a key-only `Dag.Blueprint` containing the proof architecture.

## One application boundary

Define the ambient objects, baseline assumptions, target, initial branch state, and registered strategy families. Then compose only official strategy keys. Core resolves the registrations, preserves the literal residual and accumulated evidence, validates the declaration, and returns the certified statement.

## Start with the shape of your proof

The strategy catalog is organized by mathematical job: ordered search, response classification, capacity accounting, support localization, rank and code exhaustion, exhaustive dichotomies, and target closure.

## The result is a theorem

An accepted `ofDag%` declaration exposes `problemDefinition.report.statement : PLift target.Statement`. The same report describes the validated path, proof topology, check bound, work bound, and human-readable execution summary.
