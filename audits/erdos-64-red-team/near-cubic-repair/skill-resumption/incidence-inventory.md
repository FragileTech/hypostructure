# Stage 2 restart: charge actual first-neighbour pairs

All facts and all three source-class alternatives in branch.md remain in scope.
The failed fold-response factorization remains available as a proved limitation
of that proposed construction, not as a counterexample to the residual.

The new observable is the multiplicity of extracted events at an actual triple
`(h, {a,b})`, where h is the high separator and a,b its distinct first
neighbours. Earlier Hall work assigned events to centres. This refinement keeps
the two physical incidences and asks whether the source response data bound
their repeated use. It does not assume independent arms or distinct terminals.

Present: the greedy extraction partitions removed source-pair records into
L-element events; each event has an actual high-centre handoff witness. Once a
witness is chosen for each event, the event set has a total map to triples.
This is finite choice of existing witnesses, not a capacity proof.

Accounted: source pairs are distinct records, and the extracted events are
disjoint as record sets. Unaccounted: many events may have the same triple.
Different source endpoints do not imply different initial incidences.

Candidate: bound the fibres of this map and sum the available incidence pairs.
This is different from assigning to arbitrary centre slots, but must still
prove its capacities from the retained residual. The existing marked-fan cap
applies only with a legal, pairwise compatible window labelling; an envelope's
FanSafe predicate supplies no such labelling.

Competing moves: the original response-only fold projection has been rejected;
repeating split-off arithmetic supplies no new consumer; using sublinear Type B
mass is circular because that result assumes the near-cubic estimate.

Next admission test: prove the sum bound, then inspect the exact routing output
for the fibre bound and the required marking. Neither is added to the residual.
