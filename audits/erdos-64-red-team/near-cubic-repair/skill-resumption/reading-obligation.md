## What the declared operations actually provide

DeclaredSignature.Reading.quotientImage accepts a map from the **source Value**
type to a quotient value type. Thus one must give a function on the actual
retained values, not merely a graph operation on an independently chosen piece.
Its support equation says where the value is carried, not how it is evaluated
on a replacement realization. Reading.restrict explicitly requires the value
of the restricted embedded support; it does not derive that value from the
support intersection. These are separate obligations in the inspected types.

Writing q(P)=fold(P) is consequently not yet a construction of the required
reading: P is a boundaried realization, whereas the D8 projection acts on the
source coordinate value. To make that construction, one must define the map
on those values, define its interpretation on the folded marked piece, and
prove the displayed equality for each original coordinate. A graph fold is
not itself this equation. The source pair labels, actual arm tails, return
values and realization domain remain fixed through that proof.
