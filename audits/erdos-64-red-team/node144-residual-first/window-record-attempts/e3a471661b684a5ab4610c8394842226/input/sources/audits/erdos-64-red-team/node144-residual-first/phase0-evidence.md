## Research observations (not accepted Phase 1–3 results)

- A sparse exit is the left alternative of `bottleneckRouting`, but `active.survives` eliminates it in the owner, leaving the envelope. This is an elimination of that local alternative, not closure of the selected graph.
- The positive pattern is incompatible with `HomogeneousCapsHold` on `G` (checked by `CapCheck.lean`). A cap can apply on a separate no-pattern branch; recording a handoff does not change `G` or erase its pattern.
- `SameTokenTypeBHandoffStatement` retains an existential source pattern **and** an existential envelope, but its proposition does not index that envelope by every pattern edge or by every original pair demand. The owner constructs one envelope from its selected source. The first missing inference for a quantitative continuation is a simultaneous, source-indexed multiplicity/coverage theorem for the actual routed pair families. An alternative compression continuation needs a target-complete coordinate reading for its actual replacement.
- The common Type B fan entry can be projected, but the low-surplus tail requires `surplusAtOrBelow`, which contradicts this branch’s `surplusAbove`; it is not an admissible imported premise.
- [179]/[180] pair-system Type B entries have different source keys and are outside these three [144] records.
