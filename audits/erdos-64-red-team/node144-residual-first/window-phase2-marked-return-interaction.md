# [144a] the marked return path versus the extremal source routes

Retain the entire literal [144a] predecessor on the selected `G`. Fix one actual matching or star producer and its *same* certified token, pattern, two equal-label source pairs `p,q`, chosen demands, maximal common-prefix configurations `r_p,r_q`, first separator `h`, next vertices `a,b`, first-entry arms, core `Y`, envelope region `S`, and physical skeleton `F`. The owner forces `e={a,x}∈E(G)∖F` and proves `HasReturn` for that exact ordered edge. Let `P_e=(v_0=a,v_1,…,v_t=x)` be any simple path from that `HasReturn` in `G−e`. Thus `t≥2`, every path edge differs from `e`, and `Z_e=e∪P_e` is a simple cycle of length `t+1`. The retained selection implies `¬LengthOK(t+1)`; it does not determine `t` or produce a target cycle.

The **new** object is the pair `(e,P_e)` attached to this extremally chosen source pair. The earlier Phase 2 all-cycle ledger partitioned arbitrary cycles and counted generic fan markers. It did not force a cycle containing an edge outside this selected envelope skeleton, nor index a return path by the very two routes whose common prefix is maximal. Its generic marker and exterior counts remain valid and are not counted again.

Use complete membership words rather than assume the return makes a single excursion. For every index `i=0,…,t`, record membership of `v_i` in `Y`, the left arm, the right arm, `{h}`, the common prefix, `S`, the full route union `U=V(r_p)∪V(r_q)`, the two original pair-specific supports `Z_p,Z_q`, and the two selected local buffers `B_{d_p},B_{d_q}`. These Boolean words preserve every overlap. For a disjoint endpoint label, assign priority `Y`, left arm outside `Y`, right arm outside `Y∪left`, `{h}` outside those sets, then `S` remainder, then outside `S`; separately record prefix and `U` membership. The four reviewed cases for `x` (core, left arm outside core, right arm outside core and left arm, outside `S`) and `x≠h` are exactly the closing-edge endpoint cases, not a restriction on the interior vertices of `P_e`.

For each edge of `P_e`, its endpoints and actual edge membership give exactly one physical class: `F`; extra internal `I=E(G[S])∖F`; boundary `δ_G(S)`; or an edge wholly outside `S`. Record the entire class word, not just its total. The closing edge `e` is in `I` when `x∈S`, and in `δ_G(S)` when `x∉S`; it is never in `F`. The path can alternate across `δ_G(S)` several times, visit more than one exterior component, re-enter `U` more than once, and traverse either source route. None of those cases is excluded by `HasReturn`.

Because `v_0=a∈U`, define the first later route encounter by the least `i>0` with `v_i∈U`, if it exists. An immediate encounter (`i=1`), a later re-entry after an excursion, and no later encounter are distinct. For each maximal interval of indices with `v_i∉U`, retain its entry and exit vertices and the component of `G−U` it visits; intervals may share a physical component. Perform the analogous calculation for `S`. Equal landing at the same assigned neighbour, an endpoint in the other core vertex, and arm intersections are retained by the membership words rather than silently identified. The first encounter can be at a prefix vertex, `h`, either arm, core, or a post-first-entry suffix, and may lie in several of those named sets.

The support words are essential. `P_e` is a graph path, not a `RoutingConfiguration` in `Z_p` or `Z_q`. Even if some segment stays in `Z_p`, a proposed splice must separately check its new path is simple, begins at the original root, ends in the original local buffer, and stays in the *same pair's* support. The return path has no such validity fields. Conversely, the first vertex or edge leaving one support is an exact obstruction to that splice, not a counted physical capacity unit by itself. The same caveat applies to the other support and to a shared star demand.

The marked cycle uses at least the one non-`F` edge `e`, but its other non-`F` edges and their repeated source uses cannot be charged as independent rank units from this one cycle. If `x` is outside `S` or in a different component of `F`, there need not be an `F` path from `a` to `x`; a shorter `F∪{e}` cycle cannot be assumed. If such an `F` path does exist, it gives another actual cycle and its length also fails `LengthOK`, but it need not share the length of `Z_e` or consume a distinct source pair.

This inventory exposes one unmeasured interaction for a later Phase 3 choice: **where a marked `G−e` return first meets the extremal source routes, and whether its intervening segments are admissible in the original pair-specific routing supports**. The serious alternative remains using its physical/exterior rank payment; the accepted account currently gives only a global one-envelope lower bound with no per-pair multiplicity consumer.
