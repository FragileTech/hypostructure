Proof. f118 supplies an edge on c and an endpoint y in P minus N internal to Z. f022 gives local-or-mixed for this SAME c. The local alternative would give an accepted cycle of ret_P, contrary to f029, so c meets at least two distinct boundary labels. Traverse the cyclic order of c in both directions from y until the first boundary label in each direction. Finiteness guarantees these first positions. They are distinct: otherwise the simple cycle would revisit that label before encountering its second distinct label. The arc between these two first positions through y has no internal boundary label. An edge incident to a piece-internal vertex cannot be context-owned, by the sum types in glueGraph_adj_iff. Decoding preserves edges and distinct vertices (ReadingProfiles.pieceDecode_injective); hence it is a simple path in G[Z] with vertices in P. Its endpoints each have a P-neighbour on the arc, so their P counts are positive. Equal profiles give positive N counts and membership in N by retained_boundaryDegree and mem_of_profile_eq. Both are therefore active common labels. This reasoning analyzes a subarc already present in c; it constructs no new test, context, replacement, or cycle.

## Strongest rival: a02
At an active boundary b of this same tuple, put C_b=N_G(b) intersect P intersect N, L_b=N_G(b) intersect (P minus N), R_b=N_G(b) intersect (N minus P). Since P,N subset Z and b belongs to both, equal reading counts give |C_b|+|L_b|=|C_b|+|R_b|, hence |L_b|=|R_b|. Thus if a private edge of c touches b, there is an opposite-reading private neighbour at b. Such a neighbour cannot be a boundary vertex: its edge within N would transfer its boundary membership into P by f115. Both private-neighbour sets are internal. This is a real target-relevant constraint on the incidence supporting the profile-equality clause. In a nested-support case one private-neighbour set is empty, so both are empty. In whole cases this agrees with the retained no-boundary-neighbour restriction.

This rival is strong because it pins neighbour identities up to balanced differences, beyond numerical profile equality alone. But all private edges of c may be internal, and then the boundary balance is empty on that cycle. In particular the weakest c18_02/c16_04 cell need not supply a boundary private edge.
